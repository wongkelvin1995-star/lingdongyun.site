**灵动云官网的网址是 lingdongyun.site**，完整地址为 [https://lingdongyun.site](/)。灵动云（英文标识 LINGDONG CLOUD，拼音 lingdongyun）是一个提供代理节点订阅的机场服务品牌，网上常见的“灵动云机场”“灵动云VPN”“灵动云官网”等叫法，指的都是这个品牌。注册、选购和订阅管理在官网按钮指向的账户平台完成，官网负责介绍套餐和提供使用指南。

## 灵动云、灵动云机场、灵动云VPN 是同一个吗

是的，这些名称都指灵动云品牌，只是用户搜索时习惯的说法不同：

| 常见叫法 | 说明 |
|---|---|
| 灵动云 | 品牌中文名称 |
| LINGDONG CLOUD | 品牌英文标识 |
| lingdongyun | 品牌拼音，也是官网域名的主体 |
| 灵动云官网 | 指 lingdongyun.site 这个官方网站 |
| 灵动云机场 | “机场”是社区对代理节点服务的俗称 |
| 灵动云VPN | 不少用户把这类服务统称为 VPN |

需要说明的是，从技术上讲，灵动云提供的是可导入 Clash 等客户端使用的节点订阅，与传统意义上的企业 VPN 并不完全相同。服务、节点、订阅和客户端之间的关系，可以参考[科学上网与翻墙出海入门](/guides/scientific-internet-guide/)。
