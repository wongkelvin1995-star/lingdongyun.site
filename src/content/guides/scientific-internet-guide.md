简单来说，人们常说的“科学上网”“翻墙出海”，是指通过代理服务访问跨境网络资源；而“全球加速”指的是借助分布在不同地区的服务器，改善跨境访问的连接质量。它由三部分组成：**服务**（常被称为“机场”）提供节点，**订阅**把节点信息交给你，**客户端**负责在你的设备上使用这些节点。理解了这三者的关系，大部分入门问题都能迎刃而解。使用前也请了解并遵守所在地的法律法规。

## 几个基础概念

| 概念 | 通俗解释 |
|---|---|
| 机场 | 提供代理节点的服务商，“机场”是社区里的俗称 |
| 节点 | 服务商部署在某个地区的代理服务器，一个服务通常有多个节点 |
| 协议 | 客户端与节点之间的通信方式，例如 Shadowsocks、VMess、Trojan |
| 订阅 | 一个带令牌的链接，客户端通过它获取并更新节点列表 |
| 客户端 | 安装在设备上的软件，例如基于 Mihomo 内核的 Clash Party |
| 规则 | 决定哪些网站走代理、哪些直接连接的配置 |

打个比方：机场像航空公司，节点是不同的航线，订阅是登机凭证，客户端则是帮你办理登机、选择航线的工具。

## 服务、节点与客户端如何协作

一次典型的使用过程是这样的：

1. 你在服务后台购买套餐，获得订阅链接；
2. 把订阅链接导入客户端，客户端下载节点列表；
3. 客户端根据规则判断访问的网站是否需要走代理；
4. 需要代理的流量被发送到你选定的节点，再由节点访问目标网站。

在 Mihomo 的配置中，从订阅获取的节点被称为“代理集合”，可以按设定的间隔自动更新；节点又可以被组织成“代理组”，例如手动选择组、按延迟自动选择组、故障时自动切换组等。具体操作见[Clash 节点使用指南](/guides/clash-nodes/)。

## 翻墙出海的常见使用场景

不同场景对网络的要求不同：

- **学习与查资料**：访问学术网站、技术文档、开源社区，看重连接成功率；
- **跨境办公**：使用海外协作工具、视频会议，看重延迟稳定、少断线；
- **出海业务**：跨境电商、海外社媒运营，需要稳定访问海外平台后台；
- **娱乐与内容**：观看海外视频平台，看重带宽和晚高峰表现。

先明确自己属于哪种场景，选择套餐和节点时会更有方向，可以结合[2026 机场推荐选购指南](/guides/airport-recommendation-2026/)来比较。

## 全球加速能做什么，不能保证什么

“全球加速”的原理，是让你的流量通过网络条件较好的路径抵达目的地，从而改善跨境访问速度和稳定性。但它**无法保证在任何地点、任何时间都一样快**，原因包括：

- **你所在的网络**：不同城市、不同宽带运营商到同一节点的线路质量不同；
- **时段差异**：晚间用网高峰时，跨境线路普遍更拥挤；
- **节点负载**：同时使用同一节点的人越多，单人可用带宽越少；
- **目标网站**：网站自身服务器的位置和状态同样影响速度。

因此，面对“全球秒开”“任何时间满速”之类的说法，要以自己的实际使用体验为准。观察方法可以参考[稳定节点怎么看](/guides/stable-nodes/)。

## 入门时的几个建议

- 先选一个官方渠道发布、仍在维护的客户端，不要下载来源不明的修改版；
- 确认服务提供的订阅格式与客户端兼容；
- 保管好订阅链接，它包含与账户绑定的令牌；
- 从小套餐开始，熟悉用量后再调整。

## 要点总结

- 科学上网由服务、订阅、客户端三部分协作完成；
- 节点是服务器，协议是通信方式，订阅是获取节点的带令牌链接；
- 翻墙出海的场景不同，对延迟、带宽和稳定性的侧重也不同；
- 全球加速改善的是连接路径，不能保证任何地点、任何时间都快；
- 入门时选官方客户端、确认订阅兼容、保护订阅链接。
